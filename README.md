# Refúgio Hermenêutico

Projeto organizado a partir do código gerado pelo Astra AI.

## Arquivos
- `server.js`: backend e integração com a OpenAI
- `public/index.html`: interface do aplicativo
- `data/db.json`: leituras salvas localmente
- `.env.example`: exemplo das variáveis necessárias

## Importante
Não coloque sua chave da OpenAI em arquivos públicos.
Ao publicar o projeto, configure `OPENAI_API_KEY` como variável de ambiente no serviço de hospedagem.
